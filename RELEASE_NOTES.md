# LiveSubtitles v0.1.0-alpha

Первая предварительная версия бесплатного локального перевода звука браузерной вкладки в субтитры.

## Скачать и запустить

Полностью распакуйте `LiveSubtitles-v0.1.0-alpha-Windows.zip` и запустите `START.cmd`. Затем откройте `http://127.0.0.1:8765/setup` и следуйте инструкции. Для загрузки расширения в Chrome выберите папку `extension` на странице `chrome://extensions` в режиме разработчика.

Нужны Windows x64, Chrome 116+ и установленный Python для первоначальной настройки. Первый запуск устанавливает совместимое окружение Python 3.12, библиотеки и модели. Видеокарта и платный API не требуются. После скачивания моделей распознавание и перевод работают локально.

## Что входит

- Расширение с субтитрами поверх видео, выбором языка, размера текста и отступа.
- Локальный сервер Whisper base + Argos/CTranslate2; по умолчанию английский → русский.
- Код подключения, проверка origin WebSocket и ограниченная очередь аудио.
- Исходники, тесты, инструкция, лицензия MIT и сведения о сторонних компонентах.
- `SHA256SUMS.txt` для проверки целостности ZIP.

## Статус проверки

- Тесты сегментации, PCM, протокола, аутентификации, ограниченной очереди и состава релизного архива.
- Распознавание синтезированной английской речи и перевод на русский локальными моделями.
- Получение перевода по протоколу сервера при заблокированных внешних сетевых соединениях.
- Загрузка расширения, настройки, расположение субтитров и fullscreen контейнера в отдельном профиле Edge/Chromium.

## Ограничения alpha

Перевод появляется с задержкой в несколько секунд: сначала системе нужно услышать фразу. Синхронизация 1:1 по таймкодам и предварительный перевод дорожки субтитров пока не реализованы. Совместимость с Prime Video не проверена. Полный захват звука реальной вкладки именно в Google Chrome ещё не проверен.

Защищённые плееры могут ограничивать захват. Субтитры не отображаются в нативном fullscreen самого video/стороннего iframe и в режиме «картинка в картинке».

О работе с данными см. `PRIVACY.md`. Модели, библиотеки, кеши, коды подключения и другие локальные данные не включаются в опубликованные исходники и ZIP.
