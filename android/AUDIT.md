# Проверка Android 0.1.2 alpha

## Личные данные и публикация

Проверяются исходники, содержимое APK и архива исходников, а также метаданные коммитов публикуемой ветки. Поиск включает локальные пути, известные личные маркеры, имя компьютера, ключи API, токены и пароль подписи. Ключи подписи, локальные настройки сборки, модели, логи и кеши исключены из публикации. Публичный ник qecervov и запрошенные ссылки проекта сохранены. Коммиты используют скрытый адрес GitHub вместо личной почты.

Публикация не может стереть чужие клоны или старые кешированные страницы GitHub. После исправления истории старая версия коммита может оставаться доступна по прежней ссылке. Полное удаление кеша требует обращения в GitHub Support: https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository

## Данные пользователя приложения

- Распознавание и перевод выполняются локально. В коде нет отправки аудио или текста, аналитики, рекламы, регистрации аккаунтов и автоматических отчётов об ошибках.
- Сеть в приложении используется для загрузки закреплённых моделей по HTTPS с проверкой размера и SHA-256. Внешние ссылки открываются по действию пользователя. Загрузчики моделей получают обычные сетевые метаданные, включая IP; аудио и текст им не передаются.
- В памяти обрабатывается звук выбранного UID приложения. Нет чтения микрофона, камеры, контактов, SMS, местоположения, идентификаторов рекламы или истории браузера. RECORD_AUDIO требуется Android для AudioPlaybackCapture.
- Хранятся только модели и настройки: выбранное приложение, язык, размер текста и показ промежуточного текста. Аудиофайлы, история и отдельная база списка приложений не создаются.
- Только launcher-activity экспортирована; службы загрузки и захвата не экспортированы. HTTP без TLS запрещён. Облачный бэкап отключён; все каталоги исключены из облачного резервного копирования и переноса между устройствами Android 12+.
- Правила переноса проверены также в ресурсах собранного APK. Основание: https://developer.android.com/identity/data/autobackup#xml-changes-android-12

## Зависимости

- Whisper 1.7.6, CTranslate2 4.8.1, SentencePiece 0.2.1. Версии и ревизии закреплены в native-sources.json.
- CTranslate2 обновлён с 4.6.0 для устранения CVE-2026-102566 и CVE-2026-102567. Исправления: https://github.com/OpenNMT/CTranslate2/releases/tag/v4.8.1
- SentencePiece обновлён с 0.2.0 для устранения CVE-2026-1260. Исправление: https://github.com/google/sentencepiece/releases/tag/v0.2.1
- Повторный запрос OSV по трём закреплённым Git-ревизиям не вернул известных уязвимостей. Это не полный аудит всех сторонних компонентов и не гарантия отсутствия неизвестных уязвимостей.
- SHA-256 Gradle Wrapper JAR совпадает с официальным значением Gradle 8.11.1. Дистрибутив Gradle также проверяется по закреплённому SHA-256.

## Проверки сборки

- Финальный release APK: versionCode 3, versionName 0.1.2-android-alpha, minSdk 29, targetSdk 35; ARM64 и x86_64.
- 7 тестов сегментации: успешно.
- 3 проверки на Android 15 x86_64: загрузка реальных моделей и распознавание/перевод, захват синтетического источника и остановка, прозрачное окно с управлением, перетаскиванием и поворотом экрана. Все успешно. На время проверок Wi-Fi и мобильные данные выключены; модели установлены заранее. Захваченная английская фраза переведена в «Всем привет!».
- Проверка Java-классов внутри DEX: только приложение и вспомогательный код Android R8. Сторонние Java SDK отсутствуют; AndroidX используется лишь в отдельном тестовом APK.
- Android Lint: 0 ошибок, 5 предупреждений. В нативных зависимостях остаются предупреждения компилятора; они не подавлялись.
- Проверки существующего клиента Chrome/Windows: 21 Python-тест и 8 JavaScript-тестов успешно.
- Подпись APK v2 проверена, SHA-256 сертификата совпадает с прежними версиями: e2924f0070416746559491ce3603cf8178bc939cb7022528da2b882a7d3f9f6f. Обновление установлено без удаления приложения, ранее скачанные модели доступны.
- Проверка выравнивания 16 КБ успешна.
- Поиск личных маркеров и секретов в подготовленных файлах и внутреннем содержимом APK не обнаружил совпадений. Исходники упаковываются по списку разрешённых файлов. Финальный архив также проверен перед публикацией: совпадений нет. Повторная упаковка исходников даёт идентичный ZIP.

- Microsoft Defender: выборочное сканирование папки релиза завершено, обнаружений для опубликованных APK и ZIP нет. Защита включена, антивирусные базы актуальны на момент проверки.

## Границы проверки

Проверка на эмуляторе не подтверждает работу на конкретном физическом телефоне, во всех плеерах и видеосервисах. Скорость и точность распознавания не гарантируются; короткие фрагменты могут снижать качество, при перегрузке старые фразы пропускаются. Приложение не управляет сбором данных самой ОС, видеоплеером и внешними сайтами. Проверки исходников, зависимостей и антивирусом не дают абсолютной гарантии отсутствия всех уязвимостей.
