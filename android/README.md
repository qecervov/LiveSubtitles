# LiveSubtitles для Android

**0.1.2 Android alpha.** Тестовая Android-версия приложения для перевода звука выбранного приложения в русские субтитры поверх его окна.

Требования: **Android 10 или новее, 64-битная система** (ARM64 для телефонов, x86_64 для эмулятора). Видеокарта, аккаунт, API-ключ и подписка не требуются. Качество и скорость зависят от речи, языка и устройства; синхронизации 1:1 нет.

## Как использовать

1. Установите APK и откройте LiveSubtitles.
2. Нажмите «Скачать модели». Загрузка составляет около 230 МБ; для установки нужно около 700 МБ свободного места. Загрузка имеет уведомление с кнопкой остановки.
3. Выберите приложение с видео и язык речи. По умолчанию выбран английский → русский.
4. Нажмите «Начать перевод». Разрешите показ поверх других приложений, захват аудио и системный сеанс захвата. После настройки наложения нажмите «Начать» ещё раз.
5. Откроется выбранное приложение. Включите видео со звуком. Белые субтитры с чёрной обводкой появятся прямо поверх видео на прозрачном фоне. Служебные сообщения исчезают через 2,5 секунды.
6. Перетаскивайте сам текст вверх или вниз. Нажмите на субтитры, чтобы открыть кнопки; через 3 секунды они скроются. После перемотки нажмите ↻ для очистки очереди.
7. Для остановки нажмите ✕ на панели, «Стоп» в LiveSubtitles или «Остановить» в уведомлении. При выключении экрана захват также останавливается.

Системный диалог может называть разрешение на аудио доступом к микрофону, а сеанс — захватом экрана. Приложение использует AudioPlaybackCapture: оно не открывает микрофон, не создаёт VirtualDisplay и не записывает изображение экрана. Источник звука ограничивается UID выбранного приложения.

## Языки и задержка

- Английская речь распознаётся Whisper и переводится локальной моделью английский → русский.
- Для русского режима показывается распознанная русская речь без перевода.
- Для других языков и автодетекта Whisper сначала переводит речь в английский, затем модель Argos/CTranslate2 переводит английский в русский. Такой промежуточный перевод может снижать качество.
- Опция «Показывать распознанный текст» показывает английский результат распознавания/промежуточного перевода; в русском режиме это русский оригинал.

Аудио отправляется на обработку после паузы 400 мс или фрагментами до 2,4 секунды (раньше 4,8). Затем требуется время на распознавание и перевод. В очереди хранится только один, самый свежий фрагмент. Фрагменты, ожидающие дольше 1,5 секунды, и результаты старше 6 секунд от начала фрагмента отбрасываются, поэтому на слабом устройстве часть речи может пропускаться. Это ограничение свежести, а не обещание фиксированной задержки. Короткие слова на границе фрагментов, шум, музыка и несколько голосов могут распознаваться неверно. Работа моделей на CPU может нагревать устройство и расходовать батарею.

## Ограничения захвата

Android позволяет приложению-источнику запретить захват собственного звука. В таком случае LiveSubtitles получит тишину; разрешения пользователя не отменяют запрет источника. Служебные и защищённые окна могут также скрывать плавающие панели.

В списке отображаются приложения с обычным значком запуска. Захватывается звук только выбранного приложения. Звук остальных приложений и микрофона не смешивается. Автоматического определения перемотки чужого плеера нет: для сброса служит кнопка ↻.

## Приватность

- Распознавание и перевод выполняются в нативных библиотеках на устройстве.
- Аудио и текст не передаются в облако и не сохраняются в историю или аудиофайлы.
- Хранятся модели и настройки: выбранное приложение, язык, размер текста и показ промежуточного текста.
- Список доступных приложений формируется локально для выбора источника, не отправляется на сервер и не записывается в отдельную базу.
- Облачное резервное копирование отключено. Для Android 12+ все каталоги приложения явно исключены из облачного бэкапа и переноса на другое устройство через `dataExtractionRules`; для старых версий также установлен `fullBackupContent=false`.
- В runtime APK нет Firebase, ML Kit, рекламных, аналитических SDK и автоматической отправки ошибок.
- Сеть используется для скачивания двух моделей с Hugging Face и Argos. Получатели загрузок видят обычные сетевые метаданные, включая IP-адрес, но не звук или субтитры. Скачанные файлы проверяются по закреплённому SHA-256.
- Telegram и GitHub открываются только по нажатию пользователя. Это внешние приложения/сайты со своими правилами обработки данных.
- ОС, браузер, воспроизводящее приложение и сторонние программы могут иметь собственные механизмы диагностики и сбора данных; LiveSubtitles ими не управляет.

## Сборка из исходников

Нужны JDK 17, Android SDK 35, Build Tools 35, NDK `27.2.12479018`, CMake `3.22.1`, Git и Python 3. Пути к SDK укажите локально через `ANDROID_HOME`/`ANDROID_SDK_ROOT` или неотслеживаемый `local.properties`.

```powershell
python prepare_native.py
.\gradlew.bat :app:testDebugUnitTest :app:lintRelease :app:assembleRelease
```

`prepare_native.py` скачивает закреплённые версии whisper.cpp, CTranslate2 и SentencePiece в неотслеживаемую папку `native`. Патч CTranslate2 отключает недоступную в Android функцию назначения потоков процессорным ядрам; используемая конфигурация не запрашивает такое назначение.

Для размещения исходников библиотек вне проекта задайте `LIVESUBTITLES_NATIVE_DIR`. Для подписи release APK задайте переменные среды `LIVESUBTITLES_KEYSTORE`, `LIVESUBTITLES_STORE_PASSWORD` и `LIVESUBTITLES_KEY_PASSWORD`; alias ключа — `livesubtitles`. Без них release APK не подписывается. Ключи и пароли в репозиторий не включаются. Для разработки можно собирать `:app:assembleDebug` с обычной отладочной подписью Android.

Тестовый модуль `fixture` воспроизводит синтезированную английскую речь и явно разрешает захват своего звука. Он не входит в APK LiveSubtitles. Android instrumented tests используют AndroidX только в отдельном тестовом APK; в пользовательском APK эти зависимости отсутствуют.

```powershell
.\gradlew.bat :fixture:assembleDebug :app:assembleReleaseAndroidTest
```

## Сторонние компоненты

Собственный код приложения распространяется на условиях MIT из корня проекта. Нативные библиотеки имеют собственные лицензии; их тексты включены в APK и доступны через «Лицензии и сторонние компоненты». Модели скачиваются отдельно и не входят в APK. Пакет модели Argos сохраняет своё описание и метаданные в приватной папке модели.

Нативные версии и ревизии указаны в `native-sources.json`; URL, размер и SHA-256 моделей — в `app/src/main/assets/models.json`.

После сборки `python scripts/build_release.py` создаёт архив Android-исходников и копию APK в `build/distributions`. Файлы выбираются по разрешённым папкам и расширениям; локальная конфигурация, ключи, модели и результаты сборки не попадают в исходники. Пароли подписи остаются только в среде локальной сборки. В Git используются публичный ник и скрытый адрес GitHub вместо личной почты.

Обновление APK поверх прежней Android-версии сохраняет скачанные модели и настройки. Для проверки подписи используется SHA-256 сертификата: `e2924f0070416746559491ce3603cf8178bc939cb7022528da2b882a7d3f9f6f`.
