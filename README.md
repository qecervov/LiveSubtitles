# LiveSubtitles — бесплатные субтитры с переводом

**v0.1.0-alpha · Windows x64 · Chrome 116+ · MIT**

**Это предварительная версия.** Перевод по звуку идёт с задержкой в несколько секунд; синхронизация 1:1 пока не реализована. Совместимость с Prime Video не проверена.

Расширение Chrome + локальный сервер для Windows. Слушает **звук выбранной вкладки**, распознаёт речь Whisper и переводит текст Argos Translate. По умолчанию: английская речь → русские субтитры. Работает с аудио даже без встроенных субтитров на сайте.

Подписок и API-ключей нет. Во время перевода звук и текст остаются на компьютере. Для установки зависимостей и первого скачивания каждой языковой модели нужен интернет. Модели не включены в ZIP.

## Приватность

- Захват звука начинается только после нажатия «Начать перевод» и относится только к выбранной вкладке.
- Аудио и субтитры обрабатываются локально; приложение не сохраняет запись и историю перевода.
- Микрофон, камера, cookies, пароли и история браузера не собираются.
- В Chrome сохраняются код подключения, выбранные языки и настройки субтитров. На компьютере сохраняются модели и служебные кеши.
- Аналитики, рекламы и автоматической отправки ошибок нет. Телеметрия Hugging Face отключена.
- При первоначальной загрузке библиотек и моделей внешние хранилища получают обычные сетевые сведения, включая IP-адрес; звук и субтитры им не передаются.
- Локальные данные, коды подключения, логи и кеши исключены из релизного архива.

Подробности, включая границы этих гарантий, — в [PRIVACY.md](PRIVACY.md).

## Установка

1. Полностью распакуйте архив в постоянную папку, например `D:\LiveSubtitles`. Не запускайте из ZIP.
2. Дважды щёлкните **START.cmd**. Оставьте окно открытым. При первом запуске устанавливаются зависимости и скачиваются модели; это может занять несколько минут.
3. Откройте в Chrome **http://127.0.0.1:8765/setup**. Дождитесь статуса «Готово»; для обновления нажмите ссылку на странице.
4. Откройте **chrome://extensions**, включите **Режим разработчика**, нажмите **Загрузить распакованное расширение**. Выберите папку **extension**, внутри которой лежит `manifest.json`.
5. Закрепите расширение через значок пазла в Chrome. Скопируйте код подключения со страницы локального сервера в поле расширения. Код нужен один раз и хранится локально.
6. Откройте страницу с видео, запустите воспроизведение со звуком, нажмите значок расширения и **Начать перевод**.

Для завершения нажмите **Стоп** в расширении. Чтобы выключить сервер, нажмите Ctrl+C в его окне. При следующем использовании достаточно START.cmd и кнопки «Начать перевод».

Если Python отсутствует, установите 64-битный [Python 3.12 для Windows](https://www.python.org/downloads/windows/), включая Python Launcher. Установщик создаёт отдельное окружение Python 3.12 в папке приложения; существующие Python-проекты не меняются. На ПК с другой версией Python для загрузки совместимой версии используется uv.

## Возможности

- Автоматическое распознавание языка или явный выбор языка речи. Для коротких реплик явный выбор обычно надёжнее.
- Перевод на русский, английский, немецкий, французский, испанский и украинский — при наличии соответствующих моделей Argos. Для некоторых пар используется промежуточный английский.
- Оригинал под переводом, размер шрифта и отступ снизу. Настройки применяются при следующем запуске перевода.
- Субтитры размещаются над самым большим видимым видео; если его нет, над iframe или внизу страницы.
- Сохранение исходного звука. Микрофон и изображение экрана не захватываются.
- Одна переводимая вкладка одновременно. Перемотка, пауза и смена скорости очищают накопленные фрагменты для видео в основной странице.
- Локальное соединение защищено кодом подключения; сервер слушает только `127.0.0.1:8765`.

## Скорость и ограничения

Это перевод небольшими фрагментами, а не синхронные заранее подготовленные субтитры. Аудио разбивается по паузам или каждые 4,8 секунды, затем распознаётся и переводится. **Ориентир задержки — несколько секунд**, точное время зависит от речи, модели и компьютера. Границы фрагментов могут разрезать слова; музыка, шум, несколько говорящих и тихая речь снижают качество. При перегрузке старые фрагменты пропускаются, чтобы не накапливать задержку. Очень тихий звук может не пройти порог детектора речи.

По умолчанию используется Whisper `base` на CPU с int8, видеокарта не обязательна. Желательно 8 ГБ ОЗУ или больше и несколько гигабайт свободного места для Python, библиотек и моделей.

Для большей скорости: откройте PowerShell в папке приложения и выполните:

```powershell
$env:WHISPER_MODEL = 'tiny'
.\START.cmd
```

Для лучшего распознавания замените `tiny` на `small`, учитывая большую нагрузку и задержку. При смене модели она скачается отдельно. Модели и кеши хранятся в `server/data`; Python и библиотеки — в скрытых папках внутри `server`.

Работа предусмотрена на обычных HTTP/HTTPS-страницах в Chrome 116+. Служебные страницы Chrome и Chrome Web Store не допускают внедрение субтитров. Защищённые плееры могут блокировать захват звука. В режиме «картинка в картинке», при нативном fullscreen самого `<video>` и fullscreen стороннего iframe HTML-субтитры поверх видео не отображаются. Используйте обычный/театральный режим или fullscreen контейнера плеера (например, стандартную кнопку полноэкранного режима YouTube). Перемотка внутри стороннего iframe может не очистить очередь автоматически — при необходимости перезапустите перевод.

После перехода на другую страницу перевод останавливается; запустите его заново. При смене языков тоже нажмите «Стоп» и «Начать перевод». Если сеть недоступна, уже скачанные модели продолжают работать; новые языки скачать не получится.

## Если не подключается

- **Нет связи с локальным сервером:** проверьте, что окно START.cmd открыто и страница `/setup` доступна.
- **Неверный код:** скопируйте его со страницы `/setup`. После удаления `server/data/connection-code.txt` сервер создаст новый код при следующем запуске.
- **Модели не загружаются:** проверьте доступ к PyPI, GitHub, Hugging Face и хранилищам моделей Argos. Ошибка выводится в окне сервера. После восстановления сети перезапустите сервер.
- **Порт занят:** закройте другое окно LiveSubtitles. Приложение использует порт 8765.
- **Нет субтитров:** убедитесь, что играет именно выбранная вкладка, звук не выключен, язык речи выбран правильно и сервер показывает «Готово».

## Проверки и исходники

Код расширения находится в `extension`, сервер — в `server`. Тесты аудиосегментации и протокола:

```powershell
py -3 -m unittest discover -s tests -p test_streaming.py -v
node --test tests/test_extension.cjs
# После установки зависимостей локального сервера:
server\.venv\Scripts\python.exe -m unittest discover -s tests -p test_server.py -v
```

Для всех тестов без скачивания моделей можно установить `tests/requirements.txt` в отдельное окружение Python и выполнить `python -m unittest discover -s tests -p "test_*.py" -v`.

Сборка релизного архива: `python scripts/build_release.py`. В `dist` появятся ZIP и `SHA256SUMS.txt`. Сборщик включает только разрешённые исходные файлы и не обходит каталоги с моделями, локальными кодами и окружениями.

Тесты протокола подменяют ML-движок детерминированным; качество перевода они не оценивают. Дополнительно проверены реальные Whisper base + английская модель Argos → русский на синтезированной речи и получение субтитра через протокол сервера с заблокированными внешними сетевыми соединениями. Это проверка работоспособности, а не гарантия качества и скорости на любом видео.

Интерфейс, сохранение настроек, положение субтитров и fullscreen контейнера проверены в отдельном профиле Microsoft Edge (Chromium). Полный захват звука реальной вкладки в Google Chrome ещё не проверен. Node.js нужен только для тестов JavaScript, для использования расширения он не требуется.

Использованы официальные реализации и документация: [Chrome tabCapture](https://developer.chrome.com/docs/extensions/reference/api/tabCapture), [offscreen-захват звука](https://developer.chrome.com/docs/extensions/how-to/web-platform/screen-capture), [faster-whisper](https://github.com/SYSTRAN/faster-whisper), [Argos Translate](https://argos-translate.readthedocs.io/en/latest/), [Starlette WebSockets](https://www.starlette.io/websockets/). У сторонних библиотек и моделей собственные лицензии.
